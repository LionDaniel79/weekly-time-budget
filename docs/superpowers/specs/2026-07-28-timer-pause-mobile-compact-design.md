# 타이머 일시정지 및 모바일 화면 압축 설계

## 목표

1. 타이머를 일시정지하고 다시 계속할 수 있게 한다.
2. 일시정지 상태와 누적 실행시간을 localStorage와 Firestore `activeTimer/current`에 함께 저장한다.
3. 앱 재실행, 화면 복귀, 다른 기기 접속에서도 동일한 타이머 상태를 복원한다.
4. 모바일 기록 내역의 날짜를 한 줄로 유지하고 각 기록 행의 세로 높이를 줄인다.
5. 모바일 통계 화면의 상단 `메뉴` 버튼을 한 줄로 유지한다.
6. 대분류 관리 마지막 일괄 적용 버튼의 표시 문구를 `저장`으로 바꾼다.

## 타이머 상태 모델

기존 필드 `userId`, `categoryId`, `note`, `startedAt`, `startedDate`, `running`은 유지한다. 다음 필드를 추가한다.

- `accumulatedMs`: 현재 실행 구간 이전까지 누적된 실제 실행시간. 기본값은 `0`.
- `resumedAt`: 현재 실행 중인 구간이 시작된 시각. 실행 중일 때만 숫자 값.
- `pausedAt`: 마지막으로 일시정지한 시각. 일시정지 상태에서 숫자 값.
- `stateChangedAt`: 마지막 시작·일시정지·계속 동작 시각. 로컬과 원격 중 더 최신 상태를 선택하는 기준.

새 타이머는 `startedAt`과 `resumedAt`을 같은 값으로 시작하고 `running: true`, `accumulatedMs: 0`으로 저장한다.

기존 타이머에는 새 필드가 없을 수 있다. 이 경우 `running !== false`이면 실행 중으로 간주하고 `resumedAt = startedAt`, `accumulatedMs = 0`, `stateChangedAt = startedAt`으로 정규화한다.

## 경과시간 계산

- 실행 중: `accumulatedMs + (현재시각 - resumedAt)`
- 일시정지: `accumulatedMs`
- 음수나 잘못된 값은 `0`으로 보정한다.

일시정지 동작은 현재 경과시간을 `accumulatedMs`로 확정하고 `running: false`, `pausedAt: 현재시각`, `resumedAt: null`로 저장한다.

계속 동작은 누적시간을 유지한 채 `running: true`, `resumedAt: 현재시각`, `pausedAt: null`로 저장한다.

종료 저장 시 기록 시간은 일시정지 구간을 제외한 실제 누적 실행시간으로 계산한다. 기존 동작과 동일하게 최소 1분으로 저장한다. 기록의 `startTime`은 최초 `startedAt`, `endTime`은 종료 버튼을 누른 시각을 사용한다.

## 로컬·원격 동기화

타이머 상태 변경은 먼저 localStorage에 기록하고 Firestore 문서를 갱신한다.

- 원격 저장 성공: 로컬과 원격이 같은 상태가 된다.
- 재시도 가능한 네트워크 오류: 로컬 상태를 유지하고 `remotePending: true`를 반환한다.
- 재시도 불가능한 오류: 변경 전 상태로 되돌리고 오류를 표시한다.

복구 시 로컬과 원격이 모두 있으면 `stateChangedAt`이 더 큰 상태를 사용한다. 로컬 상태가 더 최신이면 Firestore에 다시 반영을 시도한다. 원격 상태가 같거나 더 최신이면 원격 상태를 로컬에 저장한다.

## 타이머 UI

실행 중 버튼:

- `멈춤`
- `종료하고 저장`
- `취소`

일시정지 중 버튼:

- `계속`
- `종료하고 저장`
- `취소`

일시정지 상태에서는 1초 갱신 인터벌을 실행하지 않는다. 화면에는 확정된 누적시간을 계속 표시한다. 메뉴 진입과 `visibilitychange` 복구 로직은 새 상태 모델을 그대로 사용한다.

## 모바일 기록 내역

`max-width: 600px`에서 기록 행을 날짜·내용·삭제 버튼의 3열 구조로 유지한다.

- 날짜: `white-space: nowrap`, 작은 글꼴, 줄바꿈 금지
- 행 패딩과 열 간격 축소
- 삭제 버튼: 같은 행 오른쪽에 배치하고 높이 축소
- 메모 문단의 위아래 여백 축소
- 내용 영역에는 `min-width: 0`을 적용해 긴 문장이 날짜를 밀어내지 않게 한다.

## 모바일 메뉴 버튼

`mobile-menu`에 `white-space: nowrap`, `word-break: keep-all`, 고정 축소 방지와 최소 너비를 적용한다. 상단 제목 영역은 `min-width: 0`으로 두어 좁은 화면에서도 메뉴 문구가 두 줄로 나뉘지 않게 한다.

## 대분류 관리 문구

`category-bulk-editor.js`가 삽입하는 마지막 버튼의 표시 문구만 `대분류 변경사항 적용`에서 `저장`으로 변경한다. 저장 처리, 진행 중 문구, 성공·실패 안내는 기존 동작을 유지한다.

## PWA 캐시

변경된 JavaScript와 CSS가 홈 화면 웹앱에 즉시 반영되도록 서비스 워커 셸 캐시를 `weekly-time-budget-shell-v7`로 올린다. 기존 캐시 버전을 검사하는 테스트도 모두 v7으로 갱신한다.

## 테스트

- 기존 타이머의 새 모델 정규화
- 실행 중·일시정지 중 경과시간 계산
- 일시정지 동안 시간 증가 없음
- 계속 후 새 실행 구간만 추가
- 일시정지 상태에서 종료할 때 누적 실행시간만 저장
- 로컬과 원격 중 최신 `stateChangedAt` 선택
- 일시정지·계속 원격 저장 실패 시 로컬 유지 또는 롤백
- UI에 `멈춤`과 `계속` 버튼 및 이벤트 처리 존재
- 모바일 기록 내역 날짜 한 줄·압축 CSS
- 모바일 메뉴 한 줄 CSS
- 대분류 일괄 버튼 문구 `저장`
- 서비스 워커 v7 및 Pages 산출물 검사
