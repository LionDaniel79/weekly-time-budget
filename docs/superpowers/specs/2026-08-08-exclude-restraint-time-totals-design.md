# Exclude Restraint Goals from Aggregate Time Metrics

## Goal

대시보드와 통계의 상위 시간 지표가 사용자의 '의도적으로 투자한 시간'을 보여주도록 절제 목표 시간을 합계·평균·기간 비교에서 제외한다.

## Product rules

- 표시 이름은 변경하지 않는다. `적용 예산`, `주간 예산`, `실제 기록`, `기간 예산`, `기록한 날 기준 하루 평균` 등 기존 문구를 유지한다.
- `goalType === 'restraint'`인 대분류의 예산과 실제 기록은 상위 시간 합계에서 제외한다.
- 일간/주간 대시보드의 총 예산과 총 실제 기록에서 절제 항목을 제외한다.
- 통계의 기간 예산, 실제 기록, 하루 평균, 연간 월평균, 월간/연간 비교의 시간 및 증감 계산에서 절제 항목을 제외한다.
- 기록 일수와 기록된 월/주 판정은 기존처럼 실제 기록 존재 여부를 기준으로 유지한다. 절제 기록만 있는 날도 기록한 날로 남지만, 그 날의 절제 시간은 평균의 분자에 포함하지 않는다.
- 개별 대분류 행/표에는 성장·절제 항목을 모두 계속 표시한다.
- 목표 준수 점수 계산에는 성장·절제 항목을 모두 계속 포함한다.
- 절제 항목을 별도 상단 카드로 추가하지 않는다.
- 대시보드와 통계에 `※ 시간 합계와 평균은 절제 목표를 제외하여 계산합니다.` 안내를 작게 표시한다.

## Architecture

- `goal-domain.js`에 상위 시간 합계 포함 여부를 판정하는 단일 도메인 함수를 둔다.
- `time-budget-domain.js`의 일간/주간 요약에서 category summary 전체는 유지하고, 상위 total budget/actual만 포함 대상 항목으로 합산한다.
- `domain.js`의 통계 요약과 결합 요약에서도 동일 판정 함수를 사용한다.
- 비교 증감과 연간 월평균은 이미 total actual을 기반으로 하므로 총합 계산이 바뀌면 자동으로 새 의미를 따른다.
- `statistics-view.js`의 목표 준수 표시는 상위 시간 총합이 0이어도 절제 목표 점수가 있으면 점수를 표시하도록 분리한다.

## Verification

혼합된 성장/절제 데이터를 사용하는 회귀 테스트로 다음을 고정한다.

1. 일간 대시보드 총 예산/실제는 성장 항목만 합산하지만 category summaries와 목표 준수에는 절제가 남는다.
2. 주간 대시보드 총 예산/실제/하루 평균은 성장 항목 시간만 사용한다.
3. 주별·월간·연간 통계 총합과 평균이 성장 항목만 사용한다.
4. 월간/연간 비교 증감도 성장 항목 실제 기록만 사용한다.
5. 절제만 있는 기간에서도 목표 준수 점수는 사라지지 않는다.
6. 기존 지표 이름은 변경하지 않고 안내 문구를 표시한다.
