# 모바일 통계 화면 반응형 설계

## 목표

통계 화면의 계산 내용과 정보량은 유지하면서, 휴대폰에서 긴 가로 스크롤 없이 읽을 수 있도록 한다. 데스크톱에서는 표의 비교 효율을 유지하고, 화면 폭이 800px 이하일 때는 표를 카드형 목록으로 전환한다.

## 현재 문제

- 통계 표에 최소 너비 700~760px가 지정되어 있다.
- 셀에 `white-space: nowrap`이 적용되어 작은 화면에서도 줄바꿈되지 않는다.
- 월별·연도별 대분류 비교표는 열 수가 대분류 개수만큼 늘어나므로 모바일 가로 스크롤이 특히 길다.
- 글자 크기만 줄이는 방식은 정보 접근성과 가독성을 해친다.

## 확정한 반응형 기준

### 데스크톱 및 태블릿 가로 화면: 801px 이상

- 기존 표 구조를 유지한다.
- 표 최소 너비를 현재보다 줄이고 셀 여백을 압축한다.
- 긴 문구는 필요한 곳에서 줄바꿈을 허용한다.
- 대분류별 달성률 막대의 최소 너비를 줄여 표 전체 폭을 축소한다.
- 표 컨테이너를 화면 폭 이상으로 불필요하게 넓히지 않는다.

### 모바일: 800px 이하

- 통계 표의 `thead`는 화면에서 숨긴다.
- 각 `tr`을 독립된 카드로 표시한다.
- 각 `td`는 `data-label` 값을 이용해 `항목명 / 값`의 두 열 구조로 표시한다.
- 첫 번째 셀의 대분류명·월·연도는 카드 제목으로 강조한다.
- 달성률 막대는 카드 너비 전체를 활용한다.
- 카드 내부 값은 줄바꿈을 허용한다.
- `.statistics-table-wrap`의 가로 스크롤을 제거한다.

## 화면별 모바일 표시

### 월간·연간 대분류 달성

카드 한 개가 대분류 한 개를 나타낸다.

- 대분류 이름
- 기간 예산
- 실제 기록
- 달성률과 막대
- 남음 또는 초과 시간

### 월간·연도별 상세 비교

카드 한 개가 한 달 또는 한 해를 나타낸다.

- 기간
- 기간 예산
- 실제 기록
- 달성률
- 기록 일수
- 하루 평균
- 전월 또는 전년 대비

### 월별·연도별 대분류 예산·실제 비교

데스크톱의 가로 행렬 표를 모바일에서는 기간별 카드로 변환한다.

- 카드 제목: 월 또는 연도
- 각 대분류를 세로 목록으로 표시
- 대분류별 실제 기록 / 기간 예산 / 달성률
- 마지막에 전체 실제 / 전체 예산 / 전체 달성률

대분류 개수가 많아도 카드 안에서 세로로 늘어나므로 가로 스크롤은 생기지 않는다.

## 구현 구조

- 기존 통계 계산 로직은 변경하지 않는다.
- `statistics-ui.js`가 생성하는 모든 통계 표 셀에 의미 있는 `data-label`을 추가한다.
- 모바일 전환은 CSS 미디어 쿼리를 중심으로 구현한다.
- 대분류 행렬 표는 모바일에서 구조가 복잡하므로 전용 클래스와 셀 마크업을 사용한다.
- 별도의 화면 크기 감지 JavaScript나 데이터 재계산은 추가하지 않는다.

## 접근성 및 사용성

- 모바일에서도 본문 글자 크기는 최소 14px 수준을 유지한다.
- 카드 사이에 충분한 간격과 경계를 둔다.
- 항목명과 값의 대비를 명확하게 한다.
- 화면 회전이나 창 크기 변경 시 CSS만으로 즉시 전환된다.
- 표 의미를 유지하기 위해 HTML 자체는 계속 `table`, `tr`, `td` 구조를 사용한다.

## 테스트 기준

- 800px 이하 모바일 CSS에 표 최소 너비 제거와 카드 전환 규칙이 존재한다.
- 각 통계 셀에 `data-label`이 포함된다.
- 모바일에서 `.statistics-table-wrap`은 가로 스크롤을 만들지 않는다.
- 달성률 막대와 모든 수치가 카드 안에 유지된다.
- 데스크톱 표 구조와 통계 계산 결과는 변경되지 않는다.
- 자바스크립트 구문 검사와 기존 전체 테스트가 통과한다.

## 범위에서 제외

- 통계 계산 방식 변경
- 항목 삭제 또는 정보 축소
- 차트 라이브러리 추가
- 사용자가 직접 표·카드 모드를 전환하는 설정
