# 절제 목표 설계

## 1. 목적

기존 시간 예산은 모든 대분류를 `많이 할수록 좋은 성장 목표`로 계산한다. 여기에 스마트폰, TV, 유튜브처럼 `설정한 시간 이하로 사용할수록 좋은 절제 목표`를 추가한다.

이 기능은 다음 원칙을 만족해야 한다.

- 기존 대분류와 기존 기록의 의미를 바꾸지 않는다.
- 성장 목표와 절제 목표의 개별 달성률을 서로 다른 방향으로 계산한다.
- 전체 평가는 각 대분류의 예산시간을 가중치로 사용한다.
- 절제 목표의 실패가 다른 목표의 성과를 차감하지 않는다.
- 절제 목표는 생성할 때만 선택하고 이후 변경할 수 없다.
- 절제 목표는 앱 전체에서 이름 뒤에 `(절제)`를 표시한다.

---

## 2. 용어와 데이터 모델

### 2.1 목표 방식

대분류 문서에 다음 필드를 추가한다.

```js
goalType: 'growth' | 'restraint'
```

- `growth`: 성장 목표. 많이 기록할수록 달성률이 높아진다.
- `restraint`: 절제 목표. 예산시간 이하로 사용할수록 달성률이 높아진다.

### 2.2 기존 데이터 호환

기존 대분류에는 `goalType`이 없다. 필드가 없거나 올바르지 않은 값이면 항상 `growth`로 정규화한다.

```text
goalType 없음 → growth
goalType = restraint → restraint
그 밖의 값 → growth
```

기존 대분류를 자동 갱신하는 마이그레이션은 하지 않는다. 읽을 때 기본값을 적용하므로 기존 데이터가 그대로 작동한다.

### 2.3 목표 방식 불변성

목표 방식은 대분류 생성 시 한 번 정한 뒤 변경할 수 없다.

- 기존 대분류는 모두 성장 목표이며 절제로 변경할 수 없다.
- 새 대분류를 추가할 때만 `절제 목표` 체크박스를 제공한다.
- 체크하지 않으면 `goalType: 'growth'`로 생성한다.
- 체크하면 `goalType: 'restraint'`로 생성한다.
- 대분류 수정 화면에는 목표 방식 입력 또는 체크박스를 표시하지 않는다.
- 대분류 수정·순서 변경·일괄 저장은 기존 `goalType`을 덮어쓰지 않는다.
- 목표 방식을 잘못 선택한 경우 올바른 방식으로 새 대분류를 추가한다.

이 원칙은 과거 기록의 해석이 나중에 뒤집히는 것을 방지한다.

## 3. 대분류 관리 화면

### 3.1 대분류 추가

새 대분류 추가 영역에만 다음 체크박스를 추가한다.

```text
대분류 이름      [ 스마트폰            ]
기본 예산 시간   [ 21 ] 시간/주

☑ 절제 목표
  설정한 예산시간 이하로 사용하는 것이 목표입니다.

[대분류 추가]
```

기본 상태는 체크하지 않은 성장 목표다.

### 3.2 대분류 수정

등록된 대분류의 수정 행에는 기존과 같이 이름, 기본 예산, 순서, 삭제 기능만 제공한다. 절제 체크박스나 목표 방식 변경 기능은 제공하지 않는다.

절제 목표로 생성된 항목은 이름에 `(절제)`를 붙여 현재 방식을 확인할 수 있게 한다.

```text
스마트폰 (절제)   기본 예산 21시간
```

## 4. 공통 이름 표시

모든 화면에서 같은 규칙을 사용하도록 공통 함수를 둔다.

```js
categoryDisplayName(category)
```

반환 규칙:

```text
growth    → 기도
restraint → 스마트폰 (절제)
```

`(성장)` 표시는 붙이지 않는다. 원본 `category.name`에는 `(절제)`를 저장하지 않고 렌더링할 때만 붙인다.

다음 화면과 선택 항목에 모두 적용한다.

- 대시보드
- 시간 기록: 카운트다운·카운트업 대분류 선택
- 시간 기록: 수동 입력 대분류 선택
- 시간 예산
- 기록 내역
- 통계: 일간·주간·월간 및 대분류별 표·차트·선택 항목
- 대분류 관리

공통 함수는 이름에 `(절제)`가 중복으로 붙지 않도록 한다.

## 5. 개별 달성률

아래에서:

- `B`: 해당 기간의 예산시간(분)
- `A`: 해당 기간의 실제 기록시간(분)

### 5.1 성장 목표

`B > 0`일 때:

```text
개별 달성률 = round(A ÷ B × 100)
```

예산 3시간인 성장 목표:

| 실제 기록 | 개별 달성률 |
|---:|---:|
| 0시간 | 0% |
| 1시간 | 33% |
| 2시간 | 67% |
| 3시간 | 100% |
| 4시간 | 133% |
| 6시간 | 200% |

### 5.2 절제 목표: 엄격한 방식

`B > 0`이고 `A <= B`일 때:

```text
개별 달성률 = round(100 + ((B - A) ÷ B × 100))
             = round(200 - (A ÷ B × 100))
```

`B > 0`이고 `A > B`일 때:

```text
개별 달성률 = -round((A - B) ÷ B × 100)
```

예산 3시간인 절제 목표:

| 실제 사용 | 개별 달성률 | 설명 |
|---:|---:|---|
| 0시간 | 200% | 전혀 사용하지 않음 |
| 1시간 | 167% | 2시간 남음 |
| 2시간 | 133% | 1시간 남음 |
| 3시간 | 100% | 예산 정확히 소진 |
| 3시간 1분 | 약 -1% | 예산 초과 시작 |
| 4시간 | -33% | 1시간 초과 사용 |
| 5시간 | -67% | 2시간 초과 사용 |
| 6시간 | -100% | 3시간 초과 사용 |

예산을 넘는 순간 양수 달성률에서 음수 달성률로 전환하는 엄격한 정책을 사용한다.

### 5.3 예산 0시간

예산이 0이면 성장·절제 모두 달성률과 전체 목표 준수 계산에서 제외한다. 실제 기록시간은 그대로 저장하고 전체 실제 기록 합계에는 포함한다.

절제 목표 표시:

```text
스마트폰 (절제)
실제 2시간 / 예산 0시간
달성률 계산 제외
```

별도의 초과 경고나 음수 달성률은 표시하지 않는다.

## 6. 전체 목표 준수 점수

대시보드의 기존 `전체 달성률`을 다음으로 변경한다.

```text
목표 준수
57점
```

단위는 `%`가 아니라 `점`이다.

### 6.1 대분류별 전체 반영 점수

개별 달성률을 전체 합산용 점수로 변환한다.

```text
개별 달성률 > 100 → 100점
0 ≤ 개별 달성률 ≤ 100 → 해당 값 그대로
개별 달성률 < 0 → 0점
예산 0 → 계산 제외
```

좋은 방향의 초과 달성은 개별 화면에는 그대로 보여 주지만 다른 목표의 부족을 보충하지 않는다. 절제 목표 초과도 개별 화면에는 음수로 보여 주지만 다른 목표의 성과를 차감하지 않고 해당 항목만 0점 처리한다.

### 6.2 예산시간 가중 평균

각 대분류의 예산시간을 가중치로 사용한다.

```text
목표 준수 점수
= Σ(대분류 전체 반영 점수 × 대분류 예산시간)
  ÷ Σ(달성률 계산 대상 대분류의 예산시간)
```

최종 값은 반올림하고 0점에서 100점 사이로 제한한다.

### 6.3 계산 예시

오늘 예산:

```text
기도               성장 3시간
독서               성장 1시간
스마트폰 (절제)    절제 3시간
총 가중시간               7시간
```

기도 3시간, 독서 1시간을 모두 달성했다고 가정한다.

#### 스마트폰 1시간 사용

```text
스마트폰 개별 달성률 = 167%
전체 반영 점수       = 100점

기도       100 × 3 = 300
독서       100 × 1 = 100
스마트폰   100 × 3 = 300
합계                 700

목표 준수 = 700 ÷ 7 = 100점
```

#### 스마트폰 4시간 사용

```text
스마트폰 개별 달성률 = -33%
전체 반영 점수       = 0점

기도       100 × 3 = 300
독서       100 × 1 = 100
스마트폰     0 × 3 =   0
합계                 400

목표 준수 = 400 ÷ 7 = 약 57점
```

스마트폰 초과는 스마트폰 항목의 3시간 가중치만 잃게 하며, 기도와 독서의 성과 400은 유지한다.

### 6.4 시간 합계와 목표 준수의 분리

시간 자체는 목표 방식과 관계없이 모두 양수로 합산한다.

```text
기도       3시간
독서       1시간
스마트폰   4시간
전체 기록  8시간
```

- `전체 기록`: 모든 실제 기록시간의 단순 합계
- `이번 주 예산`: 성장 목표와 절제 목표 예산시간의 단순 합계
- `목표 준수`: 목표 방향을 반영한 예산시간 가중 점수

따라서 스마트폰을 적게 사용했다고 전체 기록시간을 더하거나 빼지 않는다. 시간 합계와 평가점수는 서로 다른 지표다.

## 7. 진행 막대

### 7.1 성장 목표

기존 방식처럼 실제 기록량이 왼쪽부터 차오른다.

```text
막대 비율 = min(A ÷ B, 1) × 100
```

기존 성장 목표의 색과 초과 표시를 유지한다.

### 7.2 절제 목표: 남은 허용시간과 초과시간

절제 막대는 사용량 누적 막대가 아니라 남은 허용시간과 초과시간을 보여 준다.

#### 예산 이내 (`0 <= A < B`)

```text
파란 막대 비율 = (B - A) ÷ B × 100
```

- 시작할 때 파란색 100%로 가득 찬다.
- 사용시간이 늘수록 파란색이 줄어든다.
- 파란색은 `아직 사용할 수 있는 남은 예산`을 뜻한다.

#### 예산 정확히 소진 (`A = B`)

```text
막대 비율 = 0%
```

막대는 빈 상태가 된다.

#### 예산 초과 (`A > B`)

```text
빨간 막대 비율 = min((A - B) ÷ B, 1) × 100
```

- 파란 막대는 완전히 제거한다.
- 초과한 비율만큼 빨간색이 왼쪽부터 새로 증가한다.
- 초과가 예산과 같거나 더 크면 빨간 막대는 100%로 유지한다.
- 정확한 초과시간과 음수 달성률은 텍스트로 계속 표시한다.

예산 3시간 예시:

| 실제 사용 | 막대 | 개별 달성률 |
|---:|---|---:|
| 0시간 | 파란색 100% | 200% |
| 1시간 | 파란색 67% | 167% |
| 2시간 | 파란색 33% | 133% |
| 3시간 | 빈 막대 | 100% |
| 4시간 | 빨간색 33% | -33% |
| 5시간 | 빨간색 67% | -67% |
| 6시간 | 빨간색 100% | -100% |
| 7시간 | 빨간색 100% 유지 | -133% |

절제 막대 상태는 `remaining`, `exact`, `overage`, `excluded`처럼 계산 결과로 분리해 UI가 직접 공식을 반복하지 않도록 한다.

## 8. 화면별 표시

### 8.1 대시보드

상단 카드:

```text
목표 준수
57점
```

대분류 행:

```text
기도
3시간 / 예산 3시간
100%

스마트폰 (절제)
4시간 / 예산 3시간
[빨간 막대 33%]
-33% · 1시간 초과 사용
```

절제 목표가 예산 안이면 `N시간 남음`, 정확히 소진하면 `예산 소진`, 초과하면 `N시간 초과 사용`을 표시한다.

### 8.2 시간 기록

카운트다운·카운트업·수동 입력의 대분류 선택 항목에 `(절제)`를 표시한다.

```text
스마트폰 (절제)
```

카운트다운 계산 방식은 기존 구현을 유지한다.

- 절제 목표의 양수 시간은 남은 허용시간이다.
- 절제 목표가 음수이면 초과 사용시간이며 타이머 숫자와 초과 안내를 빨간색으로 표시한다.
- 성장 목표의 음수는 기존과 같이 목표 초과 달성을 뜻하며 절제 경고색을 적용하지 않는다.

### 8.3 시간 예산

용어는 성장·절제 모두 기존 `예산 시간`을 유지한다.

```text
기도                 이번 주 예산 시간 21시간
스마트폰 (절제)      이번 주 예산 시간 21시간
```

합계 예산은 목표 방식과 관계없이 모든 대분류 예산시간을 더한다. 이 합계는 시간 배정 총량이며 `목표 준수` 점수와는 별도다.

### 8.4 기록 내역

대분류가 절제 목표이면 이름에 `(절제)`를 붙인다. 삭제된 대분류는 기존처럼 `삭제된 대분류`로 표시한다.

### 8.5 통계

일간·주간·월간 통계에서:

- 대분류 이름에 `(절제)`를 표시한다.
- 개별 달성률은 목표 방식에 맞게 계산한다.
- 전체 값은 `목표 준수 N점`으로 표시한다.
- 절제 목표의 진행 막대·상태·초과 문구는 대시보드와 같은 계산 결과를 재사용한다.
- 예산 0인 항목은 `달성률 계산 제외`로 표시하고 전체 점수 분모에서 제외한다.
- 실제 기록 합계와 예산 합계는 기존처럼 시간 단위로 별도 표시한다.

## 9. 기록과 과거 통계의 안정성

절제 목표는 새로 생성한 대분류에만 존재하며 생성 후 방식이 바뀌지 않으므로 현재 대분류의 `goalType`으로 과거 기록을 해석해도 의미가 변하지 않는다.

모든 새 타이머·수동 입력·자동 저장 기록에는 기록 당시의 목표 방식을 반드시 저장한다.

```js
goalType: 'growth' | 'restraint'
```

통계에서 목표 방식을 해석하는 우선순위는 다음과 같다.

```text
1. 기록에 저장된 goalType
2. 현재 대분류의 goalType
3. growth
```

이는 절제 대분류가 나중에 삭제되거나 일부 데이터가 누락되어도 기록 당시 의미를 보존한다. `goalType`은 실제 기록시간을 바꾸지 않으며 달성률과 표시 방향을 결정하는 메타데이터다.

---

## 10. 계산 모듈 경계

다음 책임을 순수 도메인 함수로 분리한다.

```text
normalizeGoalType(value)
categoryDisplayName(category)
calculateGoalAchievement({ goalType, budgetMinutes, actualMinutes })
calculateGoalContribution(achievement)
calculateGoalComplianceScore(categorySummaries)
calculateGoalProgress({ goalType, budgetMinutes, actualMinutes })
```

`calculateGoalAchievement` 결과에는 최소한 다음을 포함한다.

```js
{
  percentage,
  differenceMinutes,
  status,
  hasBudget,
  goalType
}
```

절제 목표 상태:

```text
remaining    예산이 남음
exact        예산 정확히 소진
overage      예산 초과
excluded     예산 0으로 계산 제외
```

`calculateGoalProgress` 결과에는 UI에서 바로 사용할 수 있도록 다음을 포함한다.

```js
{
  mode: 'growth' | 'remaining' | 'exact' | 'overage' | 'excluded',
  fillPercentage,
  contributionScore
}
```

화면마다 별도로 달성률·점수·막대 공식을 구현하지 않는다.

---

## 11. 오류 및 경계 처리

- 예산·실제시간은 계산 전에 0 이상의 숫자로 정규화한다.
- 예산 0은 나눗셈하지 않고 계산 제외 상태로 반환한다.
- 절제 목표의 양수·0·음수 경계를 분 단위뿐 아니라 소수 입력에서도 안정적으로 처리한다.
- 표시 달성률은 정수로 반올림한다.
- 진행 막대 비율은 0~100으로 제한한다.
- 전체 목표 준수 점수는 계산 대상 예산 합계가 0이면 `계산 제외` 상태로 반환한다.
- 기존 `goalType` 없는 대분류와 기록은 성장으로 처리한다.
- 대분류 일괄 수정은 목표 방식을 삭제하거나 변경하지 않는다.

## 12. 테스트 기준

### 데이터·불변성

- 기존 `goalType` 없는 대분류가 성장으로 정규화된다.
- 새 대분류 추가에서 체크 여부에 따라 성장·절제로 저장된다.
- 대분류 수정·일괄 저장이 기존 `goalType`을 보존한다.
- 수정 화면에는 절제 체크박스가 없다.
- 모든 새 기록에 정규화된 `goalType`이 저장된다.

### 개별 달성률

- 성장 3시간 예산에 0·1·3·4·6시간 기록 결과가 정확하다.
- 절제 3시간 예산에 0·1·2·3·4·5·6시간 기록 결과가 각각 200·167·133·100·-33·-67·-100이다.
- 절제 목표가 예산을 아주 조금 넘으면 즉시 음수로 전환된다.
- 예산 0은 계산 제외다.

### 전체 목표 준수

- 좋은 방향의 100% 초과는 100점까지만 반영한다.
- 절제 음수는 전체 계산에서 0점 처리한다.
- 기도 3시간, 독서 1시간, 스마트폰 절제 3시간 예시에서 스마트폰 1시간 사용은 100점이다.
- 같은 예시에서 스마트폰 4시간 사용은 약 57점이다.
- 절제 초과가 다른 목표의 점수를 차감하지 않는다.
- 예산 0인 항목은 분모와 가중치에서 제외한다.
- 시간 합계는 목표 준수 계산과 독립적으로 유지된다.

### 진행 막대

- 절제 0시간 사용은 파란색 100%다.
- 1시간 사용은 파란색 약 67%다.
- 2시간 사용은 파란색 약 33%다.
- 3시간 사용은 빈 막대다.
- 4시간 사용은 파란색 없이 빨간색 약 33%다.
- 5시간 사용은 빨간색 약 67%다.
- 6시간 이상은 빨간색 100%로 제한된다.

### 표시 범위

- 절제 대분류가 대시보드, 시간 기록, 예산, 기록 내역, 통계, 대분류 관리에서 모두 `(절제)`로 표시된다.
- 성장 대분류에는 별도 표시가 붙지 않는다.
- `(절제)`가 중복으로 붙지 않는다.
- 대시보드의 상단 명칭이 `목표 준수`, 단위가 `점`으로 표시된다.
- 절제 카운트다운이 음수일 때 빨간색으로 표시된다.

### 회귀

- 기존 성장 목표의 기록·타이머·예산·통계 계산이 유지된다.
- 기존 카운트다운·카운트업 복구와 오프라인 저장이 유지된다.
- 기존 대분류 일괄 수정과 순서 변경이 유지된다.
- 서비스 워커에 새 계산 모듈과 화면 변경 파일이 포함된다.
