# 주간 시간 예산: 주일 포함·선택 유지·대분류 정렬·통계 설계

## 목표

현재 앱을 다음 네 방향으로 확장한다.

1. 모든 기록과 통계에서 월요일부터 주일까지 포함한다.
2. 타이머와 수동 입력에서 마지막으로 선택한 대분류를 저장 후에도 유지한다.
3. 대분류 관리에서 사용자가 표시 순서를 바꿀 수 있게 한다.
4. 통계 탭을 추가해 월간·연간 통계와 월별·연도별 비교를 제공한다.

## 범위

### 포함

- 주간 범위를 월요일~주일로 변경
- 대시보드, 주간 예산, 달성률, 월간 통계, 연간 통계, 비교 통계에 주일 포함
- 타이머와 수동 입력의 마지막 선택 대분류 유지
- 마지막 선택값을 브라우저 로컬 저장소에 보관
- 대분류 위·아래 이동
- 대분류 순서를 Firestore의 `order` 값으로 저장
- 통계 메뉴와 통계 화면 추가
- 월간 통계
- 연간 통계
- 월간 비교
- 연도별 비교
- 보관된 대분류를 과거 통계에 원래 이름으로 포함

### 제외

- 사용자 지정 주 시작 요일
- 통계 데이터 내보내기
- PDF 보고서
- AI 해석 보고서
- 여러 사용자의 통계 공유

## 주간 범위 정책

주간 범위는 월요일 00:00부터 주일 23:59까지다.

- 대시보드 주간 범위 표시: `월~주일`
- 주간 예산: 7일 전체를 위한 예산
- 주간 실제 기록: 주일 기록 포함
- 달성률: 주일 포함 실제 기록 ÷ 해당 주 예산
- 기존의 `주일 기록 제외` 안내와 필터는 제거

기존 기록 데이터는 수정하지 않는다. 날짜 문자열을 기준으로 새 범위 계산에 포함한다.

## 마지막 선택 대분류 유지

타이머와 수동 입력은 각각 독립적으로 마지막 선택값을 기억한다.

### 상태

- `lastTimerCategoryId`
- `lastManualCategoryId`

### 저장 위치

브라우저 `localStorage`를 사용한다.

키 예시:

- `weekly-time-budget:last-timer-category:<uid>`
- `weekly-time-budget:last-manual-category:<uid>`

사용자 ID를 키에 포함해 같은 브라우저에서 여러 계정이 섞이지 않게 한다.

### 동작

- 사용자가 대분류를 선택하면 즉시 마지막 선택값으로 저장
- 타이머 시작 후 선택값 유지
- 타이머 종료·저장 후에도 선택값 유지
- 수동 입력 저장 후에도 선택값 유지
- 새로고침 후에도 복원
- 선택했던 대분류가 삭제되거나 보관되면 `선택하세요`로 초기화

메모, 날짜, 시작·종료 시각은 기존처럼 새 입력 상태로 초기화한다. 대분류만 유지한다.

## 대분류 순서 변경

각 활성 대분류 행에 다음 버튼을 표시한다.

`위로 / 아래로 / 수정 / 삭제`

### 동작

- `위로`: 바로 위 대분류와 순서 교환
- `아래로`: 바로 아래 대분류와 순서 교환
- 첫 항목의 위로 버튼 비활성화
- 마지막 항목의 아래로 버튼 비활성화
- 순서 변경 시 관련 두 문서의 `order` 값을 배치 저장
- 저장 완료 후 모든 화면을 다시 렌더링

### 순서 적용 범위

- 대분류 관리
- 타이머 드롭다운
- 수동 입력 드롭다운
- 이번 주 예산
- 대시보드 대분류별 달성률
- 통계 대분류별 표와 그래프

보관된 대분류는 활성 대분류 순서에서 제외한다. 과거 통계에서는 보관 당시의 `order`를 사용하되, 값이 없으면 목록 끝에 배치한다.

## 통계 화면 구조

왼쪽 메뉴에 `통계`를 추가한다.

통계 화면 내부에는 네 개의 하위 탭이 있다.

1. 월간 통계
2. 연간 통계
3. 월간 비교
4. 연도별 비교

## 월간 통계

사용자가 연도와 월을 선택한다.

표시 항목:

- 총 기록 시간
- 기록 일수
- 하루 평균 기록 시간
- 대분류별 기록 시간
- 대분류별 전체 비율
- 대분류별 가로 막대그래프

월 범위는 해당 월 1일부터 마지막 날까지이며 주일도 포함한다.

## 연간 통계

사용자가 연도를 선택한다.

표시 항목:

- 연간 총 기록 시간
- 기록 일수
- 기록한 날 기준 하루 평균
- 월평균 기록 시간
- 대분류별 연간 기록 시간
- 대분류별 전체 비율
- 대분류별 가로 막대그래프

범위는 1월 1일부터 12월 31일까지다.

## 월간 비교

선택한 한 해의 1월부터 12월까지를 비교한다.

표시 항목:

- 월별 총 기록 시간 막대그래프
- 월별 기록 일수
- 월별 하루 평균
- 월별 대분류 합계 표
- 전월 대비 증감 시간과 증감률

데이터가 없는 달도 0으로 표시해 12개월 축을 유지한다.

## 연도별 비교

기록이 존재하는 연도를 자동으로 수집하고 비교한다.

표시 항목:

- 연도별 총 기록 시간 막대그래프
- 연도별 기록 일수
- 연도별 하루 평균
- 연도별 대분류 합계 표
- 전년 대비 증감 시간과 증감률

데이터가 한 해뿐이면 비교 증감은 표시하지 않는다.

## 통계 데이터 처리

### 기록 기준

`entries` 컬렉션의 다음 필드를 사용한다.

- `date`
- `durationMinutes`
- `categoryId`

### 대분류 이름 해결

1. 활성 대분류에서 이름 검색
2. 보관된 대분류에서 이름 검색
3. 둘 다 없으면 `삭제된 대분류`

완전 삭제 시 연결 기록도 삭제되므로 정상 흐름에서는 세 번째 상태가 남지 않는다. 과거 버그로 남은 고아 기록에는 세 번째 이름을 사용한다.

### 집계 원칙

- 기록 한 건의 시간은 `durationMinutes` 전체를 해당 기록 날짜와 대분류에 귀속
- 자정을 넘는 기록도 현재 저장 구조상 기록 날짜 기준으로 한 날짜에 귀속
- 기록 일수는 기록이 하나 이상 있는 고유 날짜 수
- 하루 평균은 총 기록 시간 ÷ 기록 일수
- 비율은 대분류 시간 ÷ 기간 전체 시간
- 총시간이 0이면 비율은 0

## 차트 구현

외부 차트 라이브러리를 추가하지 않고 CSS 기반 막대그래프로 구현한다.

이유:

- 현재 앱이 빌드 과정 없는 정적 JavaScript 구조임
- 의존성 증가를 피함
- 월별·연도별 비교는 단순 막대그래프로 충분함

차트에는 숫자 표를 함께 제공해 접근성과 정확성을 보완한다.

## 오류 처리

- 기록 데이터 조회 실패: 통계 카드 안에 오류 안내 표시
- 잘못된 연도·월 입력: 현재 날짜로 복구
- 저장된 마지막 대분류가 존재하지 않음: 선택값 초기화
- 순서 변경 실패: 기존 목록을 다시 불러오고 오류 메시지 표시
- 통계 데이터 없음: 빈 상태 안내와 0값 요약 표시

## 테스트

### 단위 테스트

- 월요일~주일 주간 범위 계산
- 주일 기록이 주간 집계에 포함되는지 확인
- 월 경계와 윤년 2월 집계
- 연도 경계 집계
- 기록 일수 계산
- 대분류별 합계와 비율
- 월별 12개 배열 생성
- 연도별 정렬과 증감률 계산

### 수동 확인

- 타이머 저장 후 대분류 유지
- 수동 입력 저장 후 대분류 유지
- 새로고침 후 선택 복원
- 대분류 보관 후 선택값 초기화
- 순서 변경 후 모든 화면에서 같은 순서 확인
- 주일 기록이 대시보드와 통계에 포함되는지 확인
- 보관된 대분류가 과거 통계에 원래 이름으로 표시되는지 확인

## 완료 기준

- 모든 주간 계산이 월~주일 기준으로 일관됨
- 저장 후 대분류가 `선택하세요`로 돌아가지 않음
- 대분류 순서를 저장하고 전 화면에 반영함
- 통계 메뉴에서 네 종류의 통계를 실제 기록으로 조회할 수 있음
- 활성·보관 대분류 이름이 통계에 올바르게 표시됨
- 기존 CI가 통과하고 새 집계 테스트가 추가됨
