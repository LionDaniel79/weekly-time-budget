# 기록 기반 주별·월간·연간 통계 설계

## 목표

사용자가 실제로 시간 기록을 남긴 기간만 월간·연간 예산 계산에 포함하고, 주별 통계를 새로 제공한다. 주별 통계는 선택한 한 주의 전체 예산과 실제 기록을 비교하며, 월간·연간 통계는 기록이 존재하는 주·달을 기준으로 실제 예산 변동을 합산한다.

## 통계 탭 구성

통계 탭의 순서는 다음과 같다.

1. 주별 통계
2. 월간 통계
3. 연간 통계
4. 월간 비교
5. 연도별 비교

기존 모바일 반응형 표·카드 구조와 예산 대비 달성률 표시 방식은 유지한다.

## 공통 데이터 원칙

- 주간 범위는 월요일부터 주일까지다.
- 실제 기록은 `entries`의 `date`, `durationMinutes`, `categoryId`를 사용한다.
- 주간 예산은 해당 주의 `weeklyBudgets/{weekStart}.budgets` 값을 우선 사용한다.
- 해당 주의 별도 예산이 없으면 대분류의 `defaultBudgetMinutes`를 사용한다.
- 보관된 대분류는 기존 과거 기록과 통계 이름을 유지한다.
- 완전 삭제된 대분류와 연결 기록은 기존 삭제 정책대로 통계에서 사라진다.
- 예산이 0이고 실제 기록이 있으면 달성률 대신 `예산 미설정`으로 표시한다.

## 주별 통계

### 기간 선택

- 기본 선택은 현재 주다.
- 상단에 `← 이전 주`, 선택 주 날짜 범위, `다음 주 →`를 표시한다.
- 이전 주는 계속 이동할 수 있다.
- 현재 주 이후의 미래 주로는 이동할 수 없다.
- 현재 주를 보고 있을 때 다음 주 버튼은 비활성화한다.

### 계산 기준

- 선택한 주의 월요일~주일 전체 주간 예산을 사용한다.
- 해당 주에 기록이 없더라도 주간 예산 전체와 실제 0시간을 비교해 조회할 수 있다.
- 대분류별 주간 예산, 실제 기록, 달성률, 남음·초과 시간을 표시한다.
- 전체 요약에는 기간 예산, 실제 기록, 전체 달성률, 기록 일수, 기록한 날 기준 하루 평균을 표시한다.

## 월간 통계

### 포함 대상 주

선택한 달 안에 실제 기록이 한 건 이상 존재하는 주만 월간 예산 계산에 포함한다.

- 기록이 있는 주: 해당 월에 배정되는 주간 예산을 포함한다.
- 기록이 전혀 없는 주: 월간 예산에서 제외한다.
- 실제 기록은 선택한 달에 속한 기록만 합산한다.

### 월 경계 주 배분

월 경계에 걸친 주는 주간 예산을 7일 기준으로 날짜 수만큼 나누어 배분한다.

예: `7월 27일~8월 2일` 주의 독서 예산이 7시간인 경우

- 7월 배정 가능 예산: `7시간 × 5/7 = 5시간`
- 8월 배정 가능 예산: `7시간 × 2/7 = 2시간`

각 달에 실제 기록이 있을 때만 그 달의 배정 예산을 포함한다.

- 7월에 기록 있음, 8월에 기록 없음: 7월 5시간만 포함
- 7월에 기록 없음, 8월에 기록 있음: 8월 2시간만 포함
- 양쪽 달 모두 기록 있음: 7월 5시간과 8월 2시간을 각각 포함
- 양쪽 달 모두 기록 없음: 두 달 모두 제외

따라서 같은 주간 예산이 두 달에 중복되지 않는다.

### 월간 예산 정의

`월간 예산 = 선택한 달에 기록이 있는 주들의 월 배정 예산 합계`

주간 예산이 매주 달랐다면 각 주에 실제 저장된 예산 변동값을 그대로 합산한다.

## 연간 통계

### 포함 대상 달

선택한 연도 안에 실제 기록이 한 건 이상 존재하는 달만 연간 예산 계산에 포함한다.

- 기록이 있는 달: 그 달의 월간 예산과 실제 기록을 포함한다.
- 기록이 전혀 없는 달: 연간 예산에서 제외한다.

예를 들어 2026년 7월부터 기록을 시작하고 8월에는 기록이 없으며 9월에 다시 기록했다면:

- 1월~6월: 제외
- 7월: 포함
- 8월: 제외
- 9월: 포함
- 이후 기록 없는 달: 제외

### 연간 예산 정의

`연간 예산 = 해당 연도에 기록이 있는 달들의 월간 예산 합계`

각 월간 예산은 다시 그 달에 기록이 있는 주들의 실제 주간 예산 합으로 계산한다. 따라서 연간 예산은 주마다 변동된 실제 주간 예산을 월별로 집계한 뒤 합산한 값이다.

### 연간 평균

- 기록 일수는 해당 연도에 기록이 존재하는 날짜 수다.
- 하루 평균은 `연간 실제 기록 ÷ 기록 일수`다.
- 월평균은 달력상 경과 월수가 아니라 기록이 존재하는 달 수를 기준으로 계산한다.
- 기록이 존재하는 달이 없으면 월평균은 0분이다.

## 월간 비교

- 선택한 연도에서 실제 기록이 존재하는 달만 표시한다.
- 기록이 없는 달은 표, 그래프, 대분류 비교표에서 제외한다.
- 각 달의 예산은 월간 통계와 동일한 기록 기반 계산을 사용한다.
- 전월 대비는 직전 달력 월이 아니라 이전에 실제 기록이 존재했던 달과 비교한다.

예: 7월 다음 기록 달이 9월이면 9월의 증감은 7월과 비교한다.

## 연도별 비교

- 실제 기록이 존재하는 연도만 표시한다.
- 각 연도의 예산은 기록이 존재하는 달들의 월간 예산 합이다.
- 전년 대비는 이전에 실제 기록이 존재했던 연도와 비교한다.
- 주간 예산 문서만 존재하고 실제 기록이 없는 연도는 비교 대상에 포함하지 않는다.

## 사용자 화면

### 주별 통계 상단

```text
← 이전 주   2026-07-20 ~ 2026-07-26   다음 주 →
```

주별 통계 제목은 선택 주 범위에 맞춰 갱신한다.

### 통계 요약 카드

주별·월간·연간 통계 모두 다음 항목을 기본으로 표시한다.

- 기간 예산
- 실제 기록
- 전체 달성률
- 기록 일수
- 기록한 날 기준 하루 평균

연간 통계에는 추가로 `기록이 있는 달 기준 월평균 기록 시간`을 표시한다.

### 대분류 상세

```text
대분류 | 기간 예산 | 실제 기록 | 달성률 | 차이
```

기존 데스크톱 표와 모바일 카드형 레이아웃을 그대로 사용한다.

## 계산 함수 구조

### 주 단위 요약

선택 주의 전체 예산과 실제 기록을 계산하는 전용 함수가 필요하다.

예상 인터페이스:

```js
summarizeWeeklyBudgetPeriod(entries, categories, weeklyBudgets, weekStart)
```

### 기록 주 판별

선택 월 안의 기록을 주 시작일 기준으로 묶는다.

예상 인터페이스:

```js
recordedWeekKeysForMonth(entries, year, month)
```

반환값은 해당 월 안에 실제 기록이 존재하는 주의 월요일 날짜 키 목록이다.

### 기록 달 판별

선택 연도 안에서 기록이 존재하는 달을 구한다.

예상 인터페이스:

```js
recordedMonthsForYear(entries, year)
```

### 기록 기반 월간 요약

예상 인터페이스:

```js
summarizeRecordedMonthlyBudgetPeriod(entries, categories, weeklyBudgets, year, month)
```

- 실제 기록은 해당 월 기록만 합산한다.
- 예산은 해당 월에 기록이 존재하는 주만 포함한다.
- 월 경계 주는 해당 월 날짜 수만큼 7일 비례 배분한다.

### 기록 기반 연간 요약

예상 인터페이스:

```js
summarizeRecordedYearlyBudgetPeriod(entries, categories, weeklyBudgets, year)
```

- 기록이 존재하는 달의 월간 요약만 합산한다.
- 월간 예산 합, 실제 기록 합, 대분류별 합계를 반환한다.

## 예외 처리

- 날짜가 없거나 형식이 잘못된 기록은 통계 계산에서 제외한다.
- `durationMinutes`가 숫자가 아니면 0분으로 취급한다.
- 기록이 없는 월간·연간 통계는 예산과 실제를 모두 0으로 표시하고 빈 상태 안내를 제공한다.
- 선택 주가 미래 주가 되지 않도록 UI와 계산 양쪽에서 제한한다.
- 주간 예산 문서의 일부 대분류 값만 존재하면 나머지는 기본 예산으로 보완한다.

## 테스트 기준

### 주별 통계

- 현재 주가 기본 선택된다.
- 이전 주 이동 시 정확히 7일 감소한다.
- 다음 주 이동 시 정확히 7일 증가한다.
- 현재 주에서는 다음 주 버튼이 비활성화된다.
- 기록이 없는 주도 전체 주간 예산과 실제 0시간을 표시한다.

### 월간 통계

- 기록이 없는 주의 예산은 제외된다.
- 기록이 있는 주의 주간 예산은 포함된다.
- 주별 예산 변동값이 합산된다.
- 월 경계 주는 날짜 수만큼 7일 비례 배분된다.
- 경계 주의 해당 월에 기록이 없으면 그 달 배정 예산도 제외된다.

### 연간 통계

- 기록이 없는 달은 연간 예산에서 제외된다.
- 기록이 있는 달들의 월간 예산만 합산된다.
- 월평균은 기록이 존재하는 달 수로 나눈다.
- 7월부터 기록을 시작하면 1월~6월 예산이 포함되지 않는다.

### 비교 통계

- 월간 비교는 기록이 있는 달만 표시한다.
- 연도별 비교는 기록이 있는 연도만 표시한다.
- 증감은 바로 이전에 표시된 기간과 비교한다.

### 회귀 검증

- 기존 예산 대비 달성률 계산이 유지된다.
- 보관된 대분류 이름이 과거 통계에 유지된다.
- 모바일 카드형 통계 레이아웃이 유지된다.
- 자바스크립트 구문 검사와 전체 테스트가 통과한다.

## 범위에서 제외

- 일별 통계 추가
- 사용자 정의 주 시작 요일
- 미래 주 예산 예측
- 통계 데이터의 별도 영구 저장
- 외부 차트 라이브러리 추가
