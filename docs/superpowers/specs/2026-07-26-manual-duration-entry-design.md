# 수동 입력 직접 분 기록 설계

## 목적

기존 수동 입력의 시작·종료 시각 방식은 유지하면서, 사용자가 실제 사용 시간을 분 단위로 바로 입력할 수 있게 한다. 직접 분 입력 기록도 기존 시간 기록과 동일하게 대시보드, 주별·월간·연간 통계, 비교 통계에 반영한다.

## 범위

- 수동 입력 화면에 입력 방식 선택 버튼 추가
- `시작·종료 시각`과 `분 직접 입력` 중 하나만 표시
- 직접 분 입력 기록 저장 및 기록 내역 표시
- 마지막으로 선택한 입력 방식과 대분류 유지
- 입력값 검증과 회귀 테스트 추가

타이머, 주간 예산, 통계 계산 공식, Firestore 보안 규칙은 변경하지 않는다.

## 화면 구조

수동 입력 폼 상단에 두 개의 선택 버튼을 둔다.

```text
[시작·종료 시각]  [분 직접 입력]
```

- 기본값은 현재 사용 중인 `시작·종료 시각`이다.
- 선택된 버튼은 기존 탭과 같은 활성 스타일을 사용한다.
- 선택한 방식의 입력란만 화면에 표시한다.
- 대분류, 날짜, 메모, 저장 버튼은 두 방식이 함께 사용한다.

### 시작·종료 시각 방식

```text
대분류
날짜
시작 | 종료
메모
기록 저장
```

기존 동작과 데이터 형식을 그대로 유지한다.

### 분 직접 입력 방식

```text
대분류
날짜
직접 기록할 시간 [ 30 ] 분
메모
기록 저장
```

- 숫자 입력은 정수 분 단위다.
- 입력란에는 `1` 이상의 값을 받는다.
- 화면에는 단위 `분`을 명확히 표시한다.
- 시작·종료 시각 입력란은 렌더링하지 않는다.

## 상태 관리

수동 입력 상태에 다음 값을 추가한다.

```text
manualInputMode: 'time-range' | 'duration'
manualCategoryId: string
```

- 앱을 연 직후 입력 방식은 `time-range`다.
- 사용자가 입력 방식을 바꾸면 수동 입력 화면을 다시 그리되 대분류 선택을 유지한다.
- 기록 저장 후에도 선택한 입력 방식과 대분류를 유지한다.
- 직접 분 입력 저장 후 분 입력칸과 메모만 비운다.
- 시각 방식 저장 후에는 기존 기본 시작·종료 시각을 다시 계산해 표시한다.

이 상태는 현재 브라우저 세션 안에서만 유지하며 Firestore에는 저장하지 않는다.

## 저장 데이터

### 기존 시각 입력 기록

```js
{
  categoryId,
  date,
  durationMinutes,
  startTime,
  endTime,
  note,
  source: 'manual'
}
```

### 직접 분 입력 기록

```js
{
  categoryId,
  date,
  durationMinutes,
  note,
  source: 'manual-duration'
}
```

직접 분 입력 기록에는 `startTime`과 `endTime`을 넣지 않는다. 기존 통계 코드는 `durationMinutes`, `date`, `categoryId`를 사용하므로 별도 통계 계산 변경 없이 같은 방식으로 반영된다.

## 기록 내역 표시

기록 내역은 `source`에 따라 시간 설명을 구분한다.

- `manual-duration`: `직접 입력 · 30분`
- 그 외 시작·종료 값이 있는 기록: `09:00–10:00 · 1시간`
- 오래된 기록 중 시각이 없는 경우: 시간 범위를 비워 두지 않고 기록 시간만 표시

대분류 이름, 날짜, 메모, 삭제 기능은 기존과 같다.

## 입력 검증

직접 분 입력 저장 시 다음 조건을 모두 검사한다.

- 대분류가 선택되어 있어야 한다.
- 날짜가 입력되어 있어야 한다.
- 분 값은 숫자여야 한다.
- 분 값은 정수여야 한다.
- 최소 1분, 최대 1,440분이다.

잘못된 경우 저장하지 않고 다음과 같이 안내한다.

```text
기록 시간은 1분 이상 1,440분 이하의 정수로 입력하세요.
```

시작·종료 시각 방식은 기존 `minutesBetween` 계산과 시간 범위 검증을 유지한다.

## 반응형 화면

- 두 입력 방식 버튼은 모바일에서도 같은 줄에 배치하되 공간이 부족하면 동일 너비로 줄어든다.
- 직접 분 입력 행은 숫자 입력과 `분` 단위가 한 줄에 보이게 한다.
- 360px 이하에서도 페이지 전체 가로 스크롤이 생기지 않아야 한다.

## 테스트

다음 회귀 테스트를 추가한다.

1. 수동 입력 화면에 두 입력 방식 버튼이 존재한다.
2. `분 직접 입력` 선택 시 시작·종료 필드는 사라지고 분 입력 필드가 나타난다.
3. 직접 분 입력 기록은 `source: 'manual-duration'`으로 저장되고 시작·종료 필드가 없다.
4. 1분과 1,440분은 허용한다.
5. 빈 값, 0, 음수, 소수, 1,441분은 거부한다.
6. 저장 후 입력 방식과 선택 대분류는 유지되고 분·메모 입력은 초기화된다.
7. 기록 내역에 `직접 입력 · N분`이 표시된다.
8. 직접 입력 기록이 기존 대시보드와 통계 집계에 포함된다.
9. 기존 시작·종료 시각 입력 테스트가 계속 통과한다.
10. 모바일 화면에서 직접 입력 폼이 가로로 넘치지 않는다.

## 완료 기준

- 사용자가 시작·종료 시각을 알지 못해도 분 단위로 기록할 수 있다.
- 두 입력 방식이 서로의 값을 잘못 사용하지 않는다.
- 직접 입력 기록이 모든 기존 통계에 정상 반영된다.
- 기존 수동 시각 입력과 타이머 기능에 회귀가 없다.
- 모바일과 데스크톱에서 입력 화면이 명확하고 가로 스크롤이 생기지 않는다.
